# 手动场景层

场景层位于桌面背景之上、角色之下。它复用同一套查看器和壁纸页面，Windows 与 macOS 无需另建渲染器。

## 操作

1. 在查看器中选择模型，点击左下角“场景编辑”；Windows 托盘也可选择“编辑当前模型场景…”。
2. 素材库可以选择“当前造型图片”或“桌面背景”。前者只列出该源造型目录内未被 Spine 图集引用的 PNG，后者包括已有背景的高清左右拼图和模糊整图。
3. 点击图片添加图层，选择后可在画面中拖动、滚轮缩放，或输入水平/垂直偏移与缩放数值。每层还可设置适配模式、不透明度、混合方式、显示状态和叠放顺序。列表顶部的图层在其他场景图层之上，所有场景图层均位于角色之后。
4. 点击“保存并同步壁纸”。同一模型的已打开壁纸会立即更新场景，无需重载模型。关闭编辑器后可以继续操作角色。删除全部图层再保存可恢复无场景状态。

偏移以当前画面宽高的百分比表示，以中心为原点，范围为 ±200%；缩放范围为 0.05–8，基于所选适配模式。图层变换独立于角色变换，跨屏幕按各自 CSS 视口计算。最多 16 层。

配置按稳定模型 ID 保存；同一角色的其他模型不会自动套用。切换模型时，未保存草稿保留在当前查看器内；刷新或关闭整个页面会丢失草稿。其他窗口先保存时，当前草稿不会被覆盖，需“重新载入”后继续编辑。

## 能力范围

外置 OBJ 和 PNG 不足以确定原游戏的场景布局。缺少物体变换、材质关联、相机和时间轴时不自动猜测位置，也不还原网格、粒子或 Shader。部分带 `bg` 名称的图片实际是打包纹理，整张叠加仍会看见分散部件。可改用完整的桌面背景，手动完成替代场景。

场景图片支持同名或编号导出的分离 Alpha，要求尺寸匹配。已有 Spine 模型、坐标方向和纹理修复流程保持原有行为。

## 持久化与接口

默认保存在被 Git 忽略的 `config/scenes.local.json`，可以用 `ARKNIGHTS_SCENE_SETTINGS` 指定其他配置文件。配方仅记录素材 ID 与变换，不保存资源绝对路径。使用临时文件与原子替换写入，损坏配置返回错误并保留原文件。

- `GET /api/models/:id/scene`：素材库、当前配方和修订标识。
- `PUT /api/models/:id/scene`：提交 `{ preset: { layers: [...] }, revision }`。只接受 loopback 主机的同源 JSON 请求；修订冲突返回 409。
- `GET /api/models/:id/scene-assets/:asset.png`：该模型已索引的场景图片。
- `GET /api/scene-events`：保存后的模型 ID 通知；页面按需重新读取配方，断线重连后重新同步。

新素材需使用已有目录刷新接口或重启服务后重新载入编辑器。移动或删除素材后，已有配方会保留图层并在编辑器中提示缺失，可重新选图或移除。

运行 `npm test` 验证扫描边界、布局、保存和同步接口；`npm run windows:smoke` 在独立配置下验证静态/动态模型的场景图片加载及原生窗口同步，测试不会覆盖用户的场景配置。
